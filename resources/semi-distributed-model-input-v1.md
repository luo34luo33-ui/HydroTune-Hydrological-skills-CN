# 半分布式模型输入契约 v1

本契约用于 HydroTune 后续半分布式降雨径流模型。模型专属参数、初始状态和方程不属于共同契约；每个模型的 `data-contract.yaml` 负责声明这些字段。

1. **空间单位**：模型单元使用 HydroBase 的正整数 `sub_id`，面积来自经独立 QC 的 `subbasins.csv` 的 `area_km2`。每个子流域计算一次局地产流，并显式映射到其唯一 `outlet_reach_id`。河道使用 `reach_id` 与 `downstream_reach_id`，其中 0 是流域外出口；拓扑必须无环。
2. **证据链**：消费构建和独立验证的 `result.json`，校验其相互引用、所需表的 SHA-256 及 QC。模型不得修补上游空间成果。允许的出口数量由模型契约明确；v1 XAJ 要求一个。
3. **时序**：forcing 采用 `time,sub_id` 唯一键，覆盖全部模型单元和每个规则时步。时间步秒数、时区和时间戳所指区间由模型配置显式声明。降雨、蒸发等深度通量统一为每步累计 mm；缺测不得静默填零。
4. **边界入流**：可选 `time,reach_id,Q_m3s` 表，时间戳与 forcing 同轴；未提供或未列出的组合表示无外部入流。具体进入哪个物理分量由模型声明。
5. **结果**：至少输出逐模型单元过程、逐河段入出流、出口流量、配置快照与 `result.json`；标记预热期，保存输入/产物哈希、版本、QC 和来源。不同模型可以增加专属过程列，但不重定义共同 ID、时间和单位语义。

版本变更原则：改变共同键、时空语义或边界入流含义时升主版本；新增不冲突的可选字段时升次版本。未来模型应先复用本契约，再说明自己的例外，不从某个模型的样本参数推导通用默认值。
