# 多模型出口流量概率 BMA

消费已有模型成果，以历史观测训练集合器，再应用到未来时期；命令与成员清单见[使用指南](usage-guide.md)，成果语义见[数据契约](data-contract.yaml)。使用随 skill 安装的 CLI，不临时重写概率算法。

## 适用与边界

- 至少两个成员，在同一流域出口、m³/s 单位、同一时间步长下形成概率集合；可包含零流量。
- 连续期按 `time` 对齐；洪水场次按 `event_id,time` 对齐，选取完整场次，所有训练时步等权。
- 不运行成员模型、不搜索水文模型参数、不用 NSE 排名替代混合似然，不开展指标评价、成因解释、制图或报告。

## 科学假设与决策规则

成员潜在流量 `Z_k ~ Normal(a_k + b_k Q_k, sigma_k²)`，实际流量 `Q = max(0, Z_k)`；混合权重非负且和为 1，斜率非负、标准差为正。零观测用零点概率质量，正观测用密度。广义 EM 估计偏差、尺度与权重，属于似然估计的预测分布 BMA，不执行完整参数后验采样。

- 一个集合器绑定一个出口、时间步长、时区、时序模式及固定成员集；应用按成员 ID 匹配，不能临时删除成员或重分配权重。
- 训练期间与随机种子必须显式提供。默认 5 次初始化、500 次 EM 迭代、平均对数似然相对容差 `1e-8`；只保存收敛初始化中似然最高者。
- 以训练观测和成员的最大流量归一化，保存缩放系数；归一化标准差下限 `1e-6` 是工程数值保护，不是经验误差尺度。
- 应用的全部有效时步须晚于训练结束；同一 event ID 不能同时用于训练和应用。predict 不读取观测，不更新权重。
- 均值用删失高斯期望；分位数由混合 CDF 求解，不能加权成员分位数。默认 5%、50%、95%，其中 5%—95% 是 90% 等尾预测区间。

## 输入证据与停止条件

成员清单由调用方确认出口身份、单位、时间步长和时区；各成员声明相同出口，已有成果元数据不能与声明冲突。读取上游 `result.json` 核验实际产物 SHA-256。仅接受真实出口流量；集总式 XAJ 的 `Qt` 先做路由，并提供与入流哈希一致的出口声明和预热证据。

按精确时间键对齐，剔除任一成员预热行的并集，再验证有效时间轴相同。不得重采样、移动洪峰、插值、填零或仅取非预热行的静默交集。模型成果与观测保持只读。

| QC | 症状与处理 |
|---|---|
| 缺成员、重复 ID、混用连续与场次、出口或步长冲突 | 停止，修正清单或上游成果 |
| 时间缺失、无时区、重复键、非等间隔或覆盖不一致 | 停止，回到上游整理 |
| 缺测、非有限或负流量、哈希不符、上游 FAIL | 停止，不替代失败成员 |
| 全零、恒定或不完整训练观测 | 停止，提供有效历史期资料 |
| 无初始化收敛 | 保留拟合诊断，停止且不发布集合器 |
| 重复成员预测、样本数不超过名义自由参数数 `4K-1`、参数贴近边界 | warning；权重可辨识性或样本支持不足，不能据此排名物理模型 |
| 训练与应用重叠、应用早于训练、跨集合复用场次 | 停止，重新划分训练与应用 |

## 解释与下一步

集合均值和分位数是训练样本、成员与固定误差分布条件下的预测；不保证优于每个成员。成员权重反映条件统计贡献，不是物理真实性概率。输出只定义逐时步边际分布，不定义跨时步相关性，不能直接用于洪峰／洪量轨迹不确定性分析。

集合均值通过显式模拟列交给连续或事件评价 skill；概率性能评价需要另行开展。不能把训练似然当作独立预报能力证据。
