# 数据预处理 Workflow 使用指南

## 适用输入

- 水文、气象时序文件及其元数据。
- 可选的 DEM、流域边界、出口、站点、河网、子流域或模型单元。
- 用户已确认的变量角色、单位、时区和数据连续性信息。

## 预期输出

- 经 QC 的标准化时序结构。
- 保留边界与事件标识的洪水事件集合。
- 可用时生成经检查的水文空间拓扑。
- 数据与空间分支的 readiness 结论、限制和待确认事项。

## 使用原则

- 时序记录与独立事件集合不得混为同一数据形态。
- 不跨事件填补数据或传递模型状态。
- 集总式任务不强制要求空间分支；半分布式任务必须具备可验证拓扑。
- 所有进入下游模型的字段都应能追溯到源数据、确定性处理或用户确认。
