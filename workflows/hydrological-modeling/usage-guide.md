# 水文模型构建 Workflow 使用指南

## 支持范围

- 单流域、单模型单元的集总式降雨径流模型。
- 子流域、HRU 或 response unit 通过水文拓扑连接的半分布式模型。

第一版 workflow 不覆盖完全分布式模型、二维水动力模型和地下水模型。

## 必需决策

- 建模数据形态和空间结构。
- 模型类型及其状态、参数和输入要求。
- warm-up、simulation period 和状态传递规则。
- 存在上游来流时的 routing 方法与已确认参数。

## 输出要求

输出应包含标准化模拟序列、模型配置、参数、时间范围、空间单元、软件上下文、provenance 和运行状态。失败或 warning 必须显式保留。

半分布式新安江常规模拟使用 `--output-detail outlet-only`，避免保存随时步数及空间单元数增长的内部明细；出口流量、预热标记和水量记账仍保留。需要逐子流域或河段诊断时使用 `full`。原 CLI 省略选项仍采用 full，工作流应显式传入选择。
